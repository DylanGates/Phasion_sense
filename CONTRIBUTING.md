# Contributing

Thanks for checking out this project. This repository is primarily intended for the Phasion Sense hackathon build, but small contributions and feedback are welcome.

## Ways to contribute

- Improve documentation or clarify code comments.
- Suggest small UX or UI improvements that keep the overall concept intact.
- Fix minor bugs or accessibility issues.

If you want to propose a larger change, open an issue first so scope and direction are clear.

## Development workflow

1. Create a feature branch from `main`.
2. Run the app locally from the monorepo root with `pnpm dev`.
3. Make changes inside `frontend/` unless the change is workspace-level.
4. Run `pnpm build` before opening a pull request.
5. Open a pull request with a clear description of what changed and why.
